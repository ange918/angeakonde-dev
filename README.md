# Ange Akonde — BigSixTeen

Portfolio Next.js d’Ange Akonde (BigSixTeen / JRC DIGIT), développeur full-stack à Cotonou.

UI en français, fidèle aux maquettes : accent `#18E86B`, Syne + Manrope, motion Framer Motion (ease Outstand, reveals, hero en mots, count-up, FAB WhatsApp).

## Pages

- `/` — accueil
- `/projets` et `/projets/[slug]` — réalisations et études de cas
- `/a-propos`
- `/contact` — formulaire (mailto) + WhatsApp

## Démarrage

```bash
npm install
npm run dev
```

Le site est servi sur le port `5000`.
